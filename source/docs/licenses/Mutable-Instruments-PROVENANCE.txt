This is a software integration of selected DSP algorithms. It is not the
complete firmware or hardware behavior of the original modules. Parameter
mapping, sample-rate adaptation, preset banks and the application interface
are supplied by PocketTracker Studio. Their behavior can differ from the
original hardware.

The vendor tree also retains upstream embedded hardware, bootloader and
development support files. These are not compiled by the studio target.
Their original notices remain with those source files; no claim that every
file in the vendor tree is MIT-licensed is intended.
