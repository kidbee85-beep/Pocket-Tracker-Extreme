TrackWerk factory preset library

2,304 presets: 2,048 parameter-based .pti instruments and 256 additional effect/master presets. No third-party audio samples or SoundFonts. Distributed under GPL-3.0-or-later with TrackWerk.

Effect collection: 64 Reverbs (.ptr), 64 Delays (.ptd), 96 Studio FX (.ptfx), 32 Mastering (.ptmaster), organized by category.

Android: extract the Factory-Presets ZIP into the selected media folder, preserving its Presets hierarchy. All new named effect/master factory settings are also built into the app. Use the FX Rack or Master LIBRARY row for categorized files.
Brick: the release package prepares only missing factory files and keeps edited presets. Existing samples, projects, settings and controller mappings are independent of this library.
