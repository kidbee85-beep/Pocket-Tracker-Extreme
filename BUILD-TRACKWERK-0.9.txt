TRACKWERK 0.9 — CORRESPONDING SOURCE

Layout: source/ is the complete software project; sibling font-authoring/ and
brand-authoring/ hold the preferred editable alphabets, vector geometry and
asset generators. Keep these siblings together. No personal sample library,
private demo pack, signing key, keystore.properties, local.properties or build
cache is included. UI feedback WAVs and the tiny synthetic test font remain
as software/test inputs. Website demo-download/audio copies are omitted.

ANDROID
Use source/gradlew with the Android SDK/NDK/CMake versions declared by the
project. Build assembleRelease (unsigned without your own external signing
properties). Public default application ID: com.kidbunka.trackwerk. This is a separate
installation from old PocketTracker/Extreme app IDs. Keep the old app and
export internal work first, then select the same shared media folder in the
new app. Private settings and grants cannot be inherited across app IDs.
Maintainers can opt into ptLegacyApplicationId or ptLegacyPrivateUpdate
for existing private installs; those APKs are not public release payloads. The owner's signing keys are deliberately not corresponding source.

MIYOO MINI / PLUS
Use Python3 portable builders in build-tools/, Zig0.14.1 and the exact adjacent
SDL2-mmiyoo-f6319cf9-source.tar.gz (SHA256
b4c2416b244ad5d9c208fa5939e865331880df9fb8f9e8fca3a5d2d5017af549).
Arguments: --source <this/source> --zig <zig> --cmake <cmake> --sdl-source <tar.gz>
--app-zip <matching supplied public Miyoo ZIP> --work <new empty build dir>.
The supplied deviceZIP contributes the exact SDL2 SDK binary/header matching;
its corresponding SDL source is adjacent. CortexA7 hardfloat targets glibc2.28.
Offline: PT_MIYOO_OFFLINE=ON; Plus: OFFLINE=OFF,PT_MIYOO_PLUS_ARCHIVE=ON.
Use CMAKE_SKIP_RPATH=ON. Launch scripts retain the established data namespace.

BRICK
The shell project and shell/toolchain-aarch64.cmake / build-portmaster scripts
are supplied. Use the compatible ARM64 SDL SDK and glibc2.31 target used by the
provided binary. Keep the working device launcher/helpers and user data.

PREFERRED FONTS / ART
Python3 and Pillow are required. Alphabets and SVG geometry are original
project contributions; existing font_ui.h supplies immutable layout metrics.
Regeneration/check commands from this directory:
 python3 font-authoring/author_masters.py
 python3 font-authoring/clean-author.py
 python3 font-authoring/clean-generate.py
 python3 font-authoring/generate_atlases.py --check
 python3 brand-authoring/generate_native_art.py --check
 python3 brand-authoring/install_brand_art.py
 python3 brand-authoring/build_portrait_brand_panels.py
 python3 brand-authoring/generate_help_marks.py
Vector board output can be set through TRACKWERK_DESIGN_OUTPUT. The clean
fonts keep the original six faces and Classic byte-exact in their own slots.
