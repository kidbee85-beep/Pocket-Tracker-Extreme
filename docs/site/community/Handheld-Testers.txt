Turn your handheld into a music studio — Pocket Tracker Extreme beta testers wanted

Hi, I'm Kid Bunka, maintainer of Pocket Tracker Extreme, an independent
open-source PocketTracker fork. It makes beats, samples and synth sequences
using the handheld's buttons, with a textured studio UI and detailed slicing.
The project has been developed with AI assistance.

For the original TrimUI Brick/Hammer there is a native KNULLI package and a
simple guide from a fresh card to the first sound. Existing working KNULLI
cards can install the app directly. PortMaster does not need updating first.

Android handheld owners get a separate Android 8+ APK; RG405V-class devices are
an important test target. The Linux R36S has a separate experimental community
ZIP. Please use the download for your actual operating system and device.

The website includes the feature overview, presets and illustrated tutorial:
https://kidbee85-beep.github.io/Pocket-Tracker-Extreme/
Source and feedback:
https://github.com/kidbee85-beep/Pocket-Tracker-Extreme

First reports I'd value: does it start, do D-pad/A/B/shoulders work, can you
preview/load a WAV, hear a pattern and save/reopen a project? Please include
your exact model and firmware. USB input is a separate hardware test; universal
device compatibility is not claimed. The app and all features are free.
