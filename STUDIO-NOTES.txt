Open Studio using R + SELECT from a musical tracker page, or the STUDIO
button on the Instrument page. SELECT opens the help for the current area.
The existing physical controls remain in use.

Use INSTRUMENT > LOAD for synth choices, instrument presets, samples and
SoundFonts. LIVE synth controls update an already loaded synth while the
sequence plays. DRAFT prepares a replacement before loading it. Hold L to
hear the audition root note; release it to stop. Each engine has its own
parameter pages, followed by common filter, level and envelope controls.

In Digging, search or request random suggestions, audition a selected track,
place IN/OUT markers, render the excerpt and import the local WAV for editing.
Use only material you have permission to obtain and sample. Online source
availability can change. Direct iPhone/USB interface compatibility still
requires hardware tests; emulation does not certify an attached device.

The optional 2,048-instrument factory pack contains parameter presets rather
than a third-party sample library. The Brick launcher prepares missing preset
files before opening its native window. The optional computer-side preparer
avoids that first-launch file work; see the Brick first-start guide.

Android's public application ID and release key differ from the earlier
private .debug test app. Back up media and settings before changing builds.
Read README.md for the precise beta feature and validation limits.

BETA.2 ADDITIONS
Visible RECORD on Instrument and Sample Editor, source/frame/level diagnostics,
Stop/Keep and Use Take into Edit & Slice. Direct iPhone capture remains failed
in the current user setup; this update does not claim that route is fixed.

L + SELECT opens Punch directly: eight banks of eight momentary gestures.
L/R selects the bank, D-pad selects a pad and A holds it; releasing A restores
the mix. Style now offers 32 palettes and 12 materials without resetting the
previous IDs, defaults, custom colors or controller configuration.

The program-only Brick kit replaces one executable and provides backup/rollback.
The matching Android update preserves its package/signature pair. Do not
uninstall, reset storage, reflash KNULLI or replace a whole working app folder.
